# Orbit AI - Полностью готовый проект

Современный AI-интерфейс с поддержкой диалогов, анимациями и отзывчивым дизайном.

## 📁 Структура проекта

```
Orbit_AI/
├── index.html          # Главный HTML файл
├── styles.css          # Все стили с переменными CSS
├── script.js           # Основная логика приложения
├── responses.js        # База диалогов (только данные)
├── assets/             # Папка для изображений
│   └── brain.png       # 👈 ДОБАВЬТЕ ЗДЕСЬ ваше изображение мозга
└── README.md           # Этот файл
```

## 🎨 Особенности

✅ **Полностью готовый проект** - без заглушек, работает из коробки
✅ **Современный дизайн** - темная тема с фиолетовым неоном
✅ **Плавные анимации** - загрузка, набор текста, переходы
✅ **Отзывчивый дизайн** - мобильный, планшет, ПК
✅ **Чистый JavaScript** - без фреймворков и зависимостей
✅ **Модульный код** - легко расширять и редактировать
✅ **CSS переменные** - простая кастомизация цветов

## 🚀 Быстрый старт

1. **Добавьте изображение мозга**
   - Сохраните PNG изображение мозга как `assets/brain.png`
   - Размер: 200×200px (для лучшего вида)
   - Рекомендуемый формат: прозрачный фон

2. **Запустите проект**
   - Откройте `index.html` в браузере
   - Все готово к работе!

## 🎯 Функциональность

### Главный экран
- Центрированное изображение мозга с эффектом свечения
- Название "Orbit AI" с градиентом и фиолетовым свечением
- Кнопка "Начните разговор" с glassmorphism эффектом

### Модальное окно вопросов
- Анимация снизу вверх
- Список быстрых вопросов
- Размытый фон
- Скролл для длинных списков

### Чат
- История сообщений
- Печать текста по символам
- Индикатор печати (анимированные точки)
- Автоскролл вниз
- История сохраняется в сессии

## 🔧 Кастомизация

### Измените цвета в `styles.css`
```css
:root {
    --primary-bg: #0a0a1a;           /* Основной фон */
    --accent-color: #7c3aed;         /* Фиолетовый акцент */
    --text-primary: #ffffff;         /* Белый текст */
    /* ... остальные переменные ... */
}
```

### Добавьте новые диалоги в `responses.js`
```javascript
const DIALOGS = {
    new_dialog: {
        text: "Ваш текст здесь",
        options: [
            "Вариант 1 | dialog_id_1",
            "Вариант 2 | dialog_id_2",
            "Назад | main"
        ]
    }
};
```

## 🎬 Анимации

- **float** - плавное движение мозга вверх-вниз
- **glow** - пульсирующее свечение
- **slideUp** - модальное окно появляется снизу
- **messageIn** - сообщения появляются плавно
- **typingBounce** - точки в индикаторе печати прыгают
- **titleGlow** - текст "Orbit AI" мерцает
